# TUR-BROWSER

A modern Android browser with a high-motion, polished interface.

## Version 1.8.0 — major UI update
- New settings gear replaces the central T-button mark and a dedicated settings shortcut sits in the browser header
- All native app pages share a refreshed header, colorful accent, rounded icon tiles, and smoother fullscreen transitions
- More responsive settings rows, navigation pills, address-bar focus motion, and tab card feedback
- Redesigned T quick-actions sheet with branded header and refined animation
- Download centre includes a custom vector-drawn file type icon for supported file types, download counts, status summaries, and smoother list transitions
- Quick access and news use known-brand vector SVG logos via Simple Icons, then try site SVG, Apple Touch, Android icons, icon.horse, high-resolution Google favicon, and other fallbacks
- Home screen motion is more cohesive, with animated section entrances, refined card feedback, and a floating drag ghost that follows the pointer during reordering

VPN is intentionally excluded. Ad/tracker blocking remains a lightweight hostname list, not a network-wide blocker.

## Build
GitHub Actions builds a debug APK on pushes to `main`. Download the artifact named `TUR-BROWSER-APK` from the latest successful workflow run.
